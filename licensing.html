Licensing ​

PAI-authored code, specifications, documentation, JSON Schemas, and synthetic sample documents in this distribution use Apache-2.0. Attribution is recorded in NOTICE. The license text is copied from the Apache Software Foundation.

Third-party dependencies retain their original licenses. DEPENDENCIES.json records the package versions and SPDX identifiers from the root and content lockfiles. THIRD-PARTY-NOTICES.txt contains license and notice files from installed dependencies. Optional packages for other operating systems are listed in the inventory and are installed by npm on the target system.

Run npm run licenses after installing both dependency trees to regenerate the inventory and notices. The build embeds the PAI license and attribution, plus notices for bundled dependencies, in each standalone .pai.html file. The generated content/THIRD-PARTY-NOTICES.txt describes that browser bundle.

The website has a separate lockfile at website/package-lock.json. Its build collects the installed website dependencies' license and notice texts into website/dist/THIRD-PARTY-NOTICES.txt, alongside the repository notices.

The supplied activity, service, and tutorial examples are synthetic. Dashboard SVGs were authored for this project; the historical raster diagrams were generated for the project and are included as sample artwork. External screenshots, private service snapshots, credentials, and model-session logs are excluded from the Alpha source archive.

The architecture SVGs in docs/assets/diagrams/ were generated with Archify 3.2. Each image retains the software attribution and license notices, including the license for its embedded JetBrains Mono font.

A user's document and uploaded images retain their own terms. Saving them as .pai or exporting them with the editor as .pai.html does not apply the editor's license to that content.
