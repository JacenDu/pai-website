Content Alpha 2 — 2026-11-09 ​

Candidate for independent testing; the final tester report is pending.

  • Public read CLI for catalogue, selected content, historical versions, and original image extraction, using the declared service links.
  • Publication response validation for document identity, revision, hash, and the target resource during updates.
  • English CLI help, concise publication errors, and a single developer-check command.
  • Manifest verifier and an independent tester task pack with a blank report.

The service protocol, content model, and container versions are unchanged. The previous Alpha 1 archive and developer results remain available.

Content Alpha 1 — 2026-11-09 ​

This source distribution brings the content specification, file tools, browser editor, and reference HTTP server into one installable project.

  • English protocol documents and client/server integration guides.
  • Apache-2.0 project license, dependency inventory, and bundled notices.
  • Service checks against a supplied origin, with explicit opt-in write tests.
  • A source archive with a file manifest and SHA-256 checksum.
  • Updated markdown-it from 14.1.0 to 14.3.3 following upstream parser complexity fixes; document and container versions are unchanged.

The wire protocol remains 0.1.0-draft.1, the content model remains 0.6, and the ZIP container remains version 1. .pai carries content and original images; .pai.html adds the standalone renderer and editor.

The reference server uses local publisher credentials and on-disk snapshots. Account provisioning, hosted deployment, search queries, delegated agents, withdrawal, and protocol upgrade rules remain follow-up work. The current checks exercise the declared content operations; their report records which operations were tested or skipped.
