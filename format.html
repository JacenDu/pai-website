.pai File Format ​

Content model 0.6 · ZIP container 1

The content model stores document identity, revision, Markdown blocks, layout rows, and original image assets.

File packaging ​

Property.pai.pai.html
ContainerZIPHTML
Document entrydocument.jsonJSON in script#pai-data
ImagesBinary entries under assets/Base64-encoded bytes in document data
Rendering and editingSupplied by a compatible applicationIncluded in the complete standalone export
Service upload media typeapplication/ziptext/html; charset=utf-8

Packaging-only conversion preserves document ID, revision, all common content fields, and original image bytes, including unused assets. A complete .pai.html export supports offline viewing and editing in a supported browser. Data readers extract the document JSON without executing the embedded program.

Content structure ​

Each block has a stable ID and Markdown text. Ordered layout rows reference blocks and define one-, two-, or three-column placement. Blocks reference images by asset ID. Repeated image occurrences can use different widths and alignment while sharing the original bytes.

An application may store document data and images separately and generate a file on export.

File specification · Content hashing

File CLI ​

After installation, run from the repository root:

sh
node content/cli.mjs inspect content/dist/event.pai
node content/cli.mjs convert content/dist/event.pai -o event.pai.html
node content/cli.mjs hash event.pai.html

inspect returns document information and content, omitting image encoding and editor code. convert changes packaging. hash computes the content hash. The CLI also supports content patches and original-image extraction by asset ID.

Browser editor ​

The reference editor supports text editing, Markdown-style input, image replacement and resizing, block movement, columns, and backgrounds.

CommandResult
新建 → 打开现有文件Open .pai or .pai.html
保存 → 保存 .paiDownload a content file
保存 → 导出独立 HTMLDownload a standalone editable HTML file

The editor currently uses Chinese menu labels. Saving from a published page also creates a local download. The publication client submits that file as an update.
