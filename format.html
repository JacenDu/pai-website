The .pai document format ​

A PAI document keeps text, layout, original images, and document identity together. People edit its presentation; AI tools can work with its structured content and identified blocks.

Choose a file form ​

.pai.pai.html
ContentsDocument data and original image files in a ZIP containerThe same document and images, plus rendering and editing code
Open withA compatible application or serviceA supported web browser
Typical useSave, upload, download, and process documentsShare an editable document for standalone, offline use
EditorSupplied by the applicationIncluded in the exported file

Both forms carry the same content model. Packaging-only conversion preserves document ID, revision, text, layout, and every original image.

What the document stores ​

Text uses Markdown blocks with stable IDs. Layout rows define reading order and one-, two-, or three-column placement. Blocks reference images by asset ID, so one original image can appear in several places at different sizes.

A .pai file contains document.json and its image entries. A .pai.html file embeds document JSON and image bytes together with a renderer and editor. Tools can extract that data without executing the embedded program.

An online service can store the document in its own database and asset storage, then produce a file for download.

Read the file specification · Read the content hash specification

Edit and save ​

The reference editor supports direct text editing, Markdown-style input, image replacement and resizing, block reordering, columns, and backgrounds.

Choose 新建 → 打开现有文件 to open either file form. 保存 → 保存 .pai creates a content-file download. 保存 → 导出独立 HTML creates a standalone editable HTML file. The current editor menus use Chinese labels.

Saving from a published page downloads a local file. Use the publication client to upload the changed document as an update.

Use the file tools ​

After installing the project, run these commands from the repository root:

sh
node content/cli.mjs inspect content/dist/event.pai
node content/cli.mjs convert content/dist/event.pai -o event.pai.html
node content/cli.mjs hash event.pai.html

inspect returns document information and content without image encoding or editor code. Other commands apply content patches and extract original images by asset ID.

File tools and editor guide

The current document model is 0.6, with ZIP container version 1. The file specification is maintained in English.
