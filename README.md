# PAI website

[English](https://jacendu.github.io/pai-website/) | [简体中文](https://jacendu.github.io/pai-website/zh/)

This repository contains the built public website. The protocol, reference
implementation, and website authoring sources are maintained in the
[private project repository](https://github.com/JacenDu/pai-protocol).

GitHub Pages publishes the static files from the root of `main`.
