Get started ​

The reference implementation includes the file tools, browser editor, clients, and content server. You can run the complete content workflow locally.

Use Node.js 24 or later and npm. The verification suite also requires Python 3. The commands below use a POSIX shell on macOS, Linux, or WSL.

Install and build ​

The source repository currently requires repository access. Once your account has access, clone it and build the examples:

sh
git clone https://github.com/JacenDu/pai-protocol.git
cd pai-protocol
npm ci
npm --prefix content ci
npm --prefix content run build

The examples are written to content/dist/. Open content/dist/service.pai.html in a browser to read and edit a document.

The editor's 保存 → 保存 .pai command saves a local content file. 保存 → 导出独立 HTML exports a complete editable HTML document.

Publish the project Dashboard locally ​

sh
npm run trial

The trial starts a reference service at http://127.0.0.1:4753, publishes the built Dashboard, and prints its reading URL. It stores local publisher credentials and publication snapshots under .pai-data/. Stop the process with Ctrl+C.

With the trial running, open another terminal in the project directory and read the published document:

sh
node src/read.ts http://127.0.0.1:4753 \
  --publisher pai:project-trial --document pai-project-dashboard

The client returns the selected document's ordered content, image metadata, and source URLs. The client guide shows how to publish your own files and submit updates.

Check the implementation ​

sh
npm run verify

This builds the editor and runs the file, specification, and service checks. The checks use temporary local services and make no model calls.

To check the running trial through its public interfaces:

sh
node src/check-service.ts http://127.0.0.1:4753
