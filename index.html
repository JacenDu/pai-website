PAI Protocol

PAI (Personal Agent Interaction Protocol) defines a common interface for personal AI agents to publish, update, and retrieve documents through a content service. Each block has a source link that people and AI can use to locate and cite the passage in a specific version.

Protocol architecture ​

A personal AI finds the service endpoints at GET /.well-known/pai.json. After publication, the service returns a reading page, structured content, and a download URL. The recipient can open the page or have their AI read that version.

Architecture · Client integration · Server integration

.pai ​

.pai is a document format for editing by people and AI. It packages Markdown text, page layout, and original images in one file. Editors render the page from its layout, and AI tools can read and modify the text by stable block ID. The standalone .pai.html export includes a renderer and editor for offline use in a browser.

FilePackagingRenderer and editor
.paiZIP archive: document.json and original image filesProvided by the application
.pai.htmlHTML with embedded document data and imagesIncluded in the file for offline browser use

Both representations use the same content model. Conversion preserves document ID, revision, content, layout, and original image bytes.
