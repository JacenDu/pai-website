PAI Protocol

HTTP interfaces and a document format for content publication, updates, and retrieval by personal AI applications.

Quick start
Specification

HTTP API

Service discovery, Bearer authentication, publication, updates, and versioned reads.

API specification

Document format

Markdown blocks, layout rows, and image assets. ZIP packaging in .pai; standalone HTML export in .pai.html.

File format

Reference implementation

Node.js server, publication and retrieval clients, file CLI, and browser editor.

Installation

Protocol architecture ​

Clients discover service endpoints through GET /.well-known/pai.json. The server checks publisher authorization, stores document versions, and provides structured content and file downloads.

File representations ​

FilePackagingRenderer and editor
.paiZIP archive: document.json and original image filesProvided by the application
.pai.htmlHTML with embedded document data and imagesIncluded in the file for offline browser use

Both representations use the same content model. Conversion preserves document ID, revision, content, layout, and original image bytes.
