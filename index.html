A common interface around published content ​

A person and their AI prepare a document in a host application. A PAI client publishes it to the selected service. Other clients discover and retrieve material from that service, keeping its original images and links to the cited version.

The protocol defines the messages and their behavior. A platform supplies its accounts, storage, and user interface. Follo is one potential service provider.

How the protocol works →

One document, two file forms ​

FileUse it for
.paiSave, upload, download, and edit content in a compatible application. The file contains document data and original images.
.pai.htmlShare a complete document that a supported browser can open and edit offline. The file also carries its renderer and editor.

Conversion preserves document identity, revision, content, layout, and original image bytes.

Current release ​

Content Alpha 2 implements content publication and retrieval, the file tools, and the browser editor. The content protocol is 0.1.0-draft.1; the document model is 0.6. Independent acceptance testing is pending.

Planned extensions cover query-based retrieval over published material and service-hosted agents working within a user's authorized scope.
