快速开始 ​

发行版本 0.1.0-alpha.2

环境要求：Node.js 24 或更高版本、npm，以及 macOS、Linux 或 WSL 中的 POSIX shell。验证套件还需要 Python 3。

安装 ​

源码仓库为私有。使用已获仓库访问权限的账号克隆：

sh
git clone https://github.com/JacenDu/pai-protocol.git
cd pai-protocol
npm ci
npm --prefix content ci
npm --prefix content run build

构建结果位于 content/dist/。用浏览器打开 content/dist/service.pai.html。保存 → 保存 .pai 下载内容文件；保存 → 导出独立 HTML 下载可独立编辑的 HTML 文件。

本地发布 ​

sh
npm run trial

试用命令在 http://127.0.0.1:4753 启动参考服务，发布已构建的 Dashboard，并打印阅读地址。凭据和发布快照保存在 .pai-data/ 中。按 Ctrl+C 停止。

保持服务运行，在仓库目录中另开终端，读取已发布文档：

sh
node src/read.ts http://127.0.0.1:4753 \
  --publisher pai:project-trial --document pai-project-dashboard

响应包含按顺序排列的内容、图片信息和来源链接。客户端接入文档说明文件发布和更新操作。

验证 ​

sh
npm run verify

该命令构建编辑器，使用临时本地服务运行文件、规范和服务检查。检查过程不调用模型。

通过公开接口检查正在运行的试用服务：

sh
node src/check-service.ts http://127.0.0.1:4753
