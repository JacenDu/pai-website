.pai 文档格式 ​

PAI 文档把文字、布局、原图和文档标识放在一起。人可以直接编辑呈现效果，AI 工具可以读取结构化内容并定位具体内容块。

选择文件形式 ​

.pai.pai.html
包含什么ZIP 封装中的文档数据和原始图片同一份文档和图片，加上渲染及编辑程序
用什么打开兼容的应用或服务支持的网页浏览器
主要用途保存、上传、下载和处理文档独立分享，在本地离线阅读和编辑
编辑器来自哪里由应用提供随导出文件携带

两种文件使用同一个内容模型。单纯转换封装会保留文档 ID、修订号、文字、布局和全部原始图片。

文档里保存什么 ​

文字使用带稳定 ID 的 Markdown 内容块。布局行规定阅读顺序，以及单栏、双栏或三栏的排列。内容块通过图片 ID 引用资源，同一张原图可以在多个位置按不同尺寸显示。

.pai 内部保存 document.json 和图片文件。.pai.html 把文档 JSON、图片字节和渲染编辑程序一起嵌入文件。工具可以直接提取数据，无需执行其中的网页程序。

在线服务可以把文档放在自己的数据库和图片存储中，在下载时生成文件。

编辑和保存 ​

参考编辑器支持直接改字、Markdown 类语法输入、替换和缩放图片、移动内容块、分栏及背景设置。

通过 新建 → 打开现有文件 导入两种文件。保存 → 保存 .pai 下载内容文件。保存 → 导出独立 HTML 下载可独立编辑的网页文件。

从已发布页面保存时，也会下载到本地。修改后的文档通过发布客户端上传，形成更新。

使用文件工具 ​

安装项目后，在仓库根目录运行：

sh
node content/cli.mjs inspect content/dist/event.pai
node content/cli.mjs convert content/dist/event.pai -o event.pai.html
node content/cli.mjs hash event.pai.html

inspect 返回文档信息和内容，省去图片编码与编辑器代码。其他命令支持局部修改文档，以及按图片 ID 提取原图。
