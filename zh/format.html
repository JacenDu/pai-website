.pai 文件格式 ​

.pai 把 Markdown、布局和多媒体内容封装在一个格式文件。人类能够在交互友好的页面上高效编辑，AI 能够按区块读取同一份正文原文，省去了网页、纯文本、PDF、PPT、Word等之间的来回转换。即使只修改一部分内容段落，模型也可以只处理这一block而不是全文读取，节省输入和输出 token，减少了文档体积和传输成本，大规模提升人类+AI的内容混合编辑效率。

体验 .pai 编辑器 · 内容模型 0.6 · ZIP 封装 1

文件封装 ​

属性.pai.pai.html
容器ZIPHTML
文档入口document.jsonscript#pai-data 中的 JSON
图片assets/ 下的二进制条目文档数据中经 Base64 编码的字节
渲染和编辑由兼容应用提供包含在完整的独立导出文件中
服务上传媒体类型application/ziptext/html; charset=utf-8

封装转换保留文档 ID、修订号、两种封装共有的文档字段和原始图片字节，含未被引用的图片。完整的 .pai.html 导出文件支持在兼容浏览器中离线阅读和编辑。数据读取工具直接提取文档 JSON，无需执行嵌入的程序。

内容结构 ​

每个区块都有自己的 ID 和 Markdown 正文。把一段话从左栏拖到右栏，AI 仍然可以用同一个 ID 找到它。一行可排一到三个区块。同一张原图可以用在多处，每一处都能单独调整宽度和对齐方式。

应用可以使用数据库和图片存储，在导出时生成文件。

文件规范 · 内容哈希

文件 API ​

参考读取器在内存中使用 Uint8Array 保存图片。ZIP 保存直接写入原始字节，独立 HTML 导出时编码为 Base64。现有文件 Schema 和内容哈希保持兼容。

API返回内容
readPaiFile(bytes)已校验的文档，图片为二进制数据
readMarkdown(document, blockID?)按布局阅读顺序排列的 Markdown
inspectDocument(document, blockID?)结构化内容和图片元数据
getAsset(document, assetID)原图字节的独立副本
toJSONDocument(document)图片编码为 Base64 的文档对象，用于 JSON 序列化

正文和结构化内容提取直接使用已载入文档，无需读取图片数据。校验复用未变正文的解析结果，并检查当前资源引用和布局。首次导入完整校验文件；保存写出整份文件，内容固定为开始保存时的快照。

API 用法与兼容说明（英文）

文件 CLI ​

安装项目后，在仓库根目录运行：

sh
node content/cli.mjs inspect content/dist/event.pai
node content/cli.mjs text content/dist/event.pai
node content/cli.mjs text content/dist/event.pai intro
node content/cli.mjs convert content/dist/event.pai -o event.pai.html
node content/cli.mjs hash event.pai.html

text 输出 Markdown，可指定一个区块，保留 pai: 图片引用。inspect 返回文档信息、内容和图片元数据。convert 转换封装。hash 计算内容哈希。CLI 还支持内容补丁，以及按图片 ID 提取原图。

浏览器编辑器 ​

你可以直接改字，用 Markdown 语法输入标题和列表，拖动把手给区块分栏，或拖动图片边角调整大小。

命令结果
完成保存修改后的 .pai.html 并退出编辑
导出 → .pai在阅读态下载内容文件
新建选择文件名和保存位置，再创建空白文档并填写标题

新建使用系统保存文件窗口，只申请单个文件的访问权限。文件名在系统窗口中确定，文档标题在编辑器中填写；同一会话的后续保存写回选定文件。

编辑器当前使用中文菜单。从已发布页面保存时，也会生成本地下载。发布客户端将该文件提交为更新。
